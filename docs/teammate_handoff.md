## Step 0 — Setup (everyone does this first)

```bash
# 1. Clone the repo and navigate in
cd tsp-ai-service

# 2. Create virtual environment (Python 3.12)
python3.12 -m venv .venv
source .venv/bin/activate

# 3. Install dependencies
pip install -r requirements.txt

# 4. Copy and fill in environment variables
cp .env.example .env
# Edit .env — ask the lead for DB credentials and OpenRouter key

# 5. Run DB migrations (creates the two AI tables)
psql -U $TSP_DB_USER -d training_solutions -f docs/db_migrations.sql

# 6. Index content (required before copilot works)
python -m scripts.index_content 45d3c920-abd2-4c4e-8fdf-497b9a6dd9fc

# 7. Start the API
uvicorn app.main:app --reload --port 8000

# 8. Verify at http://localhost:8000/docs
```

## Teammate 3 — RAG Pipeline

**Your grading area**: RAG & Copilot (12%, shared with Teammate 4)

**What's already done for you**:
- `ai_content_chunks` table exists in Postgres with `float[]` embeddings
- `scripts/index_content.py` — chunks and indexes accepted content into the table
- `app/retrieval.py` — `retrieve_relevant_chunks()` queries the table, embeds the query, runs cosine similarity in Python, returns top-k above threshold
- Embedding model: `sentence-transformers/all-MiniLM-L6-v2` (384 dimensions)

**What you need to improve**:

1. **PDF text extraction**:
   - Current state: only `name` + `description` fields are indexed (1-2 sentences each)
   - Real content is in Google Drive PDFs (`contents.link`)
   - Use `pypdf` or `pdfplumber` + Google Drive download to extract full text
   - Add this to `scripts/index_content.py`
   - Install: `pip install pypdf requests` and add to `requirements.txt`

2. **Improve chunking**:
   - Current: word-based chunking at 400 words with 50-word overlap
   - Consider sentence-aware chunking with `nltk.sent_tokenize` for cleaner chunks

3. **Add retrieval metrics**:
   - Implement precision/recall evaluation: given a test question, manually judge top-5 chunks
   - Add a `scripts/evaluate_retrieval.py` script

4. **Index refresh strategy**:
   - Add a `--all` flag to `index_content.py` to re-index all trainings
   - Document when re-indexing is needed in `docs/integration_plan.md`

**Key function signature** (already implemented — use it as-is from the Copilot):
```python
from app.retrieval import retrieve_relevant_chunks

chunks = await retrieve_relevant_chunks(
    tsp_client=tsp_client,
    query="What are trainer responsibilities?",
    training_id="45d3c920-...",
    top_k=5,
    similarity_threshold=0.3  # tune this
)
# Returns: list of dicts with chunk_text, module_id, lesson_id, module_name, lesson_name, similarity
```

**Current RAG quality limitation**: See `docs/limitations.md` §5. The main improvement is PDF extraction.

## Teammate 4 — Copilot & Personalization

**Your grading area**: RAG/Copilot (12%) + Personalization (8%)

**What's already done for you**:
- `POST /copilot/message` endpoint exists and is wired end-to-end
- Guardrails: 8 regex injection patterns, fallback "I don't have that information" when no chunks clear threshold
- Learner profile fetched via `tsp_client.get_learner_profile()` if `learner_id` provided
- Source attribution: each response includes `sources[]` with `module_id`, `lesson_id`, `similarity_score`
- Conversation history: last 4 messages included in prompt

**What you need to improve**:

1. **Personalization depth**:
   - Current: learner profile is included in the prompt but Gemma is only told basic facts
   - Improve: use learner's `employment_status`, `has_training_experience`, `academic_level` to explicitly adjust answer complexity and framing
   - Add different system prompts for "Beginner" vs "Intermediate" vs "Advanced" learners

2. **Multi-turn context**:
   - Current: last 4 messages included
   - Improve: add a session ID to `CopilotRequest` so conversations can be stored and retrieved
   - Build a simple in-memory session store (dict keyed by session_id) or persist to a `ai_copilot_sessions` table

3. **Unauthorized access guardrail** ← **THIS IS REQUIRED FOR DEMO**:
   - Add check: if `learner_id` is provided, verify the learner is enrolled in `training_id` (check `trainees` table)
   - If not enrolled, return guardrail response: "I can only answer questions about your enrolled training"
   - Add this to `TSPClient` as: `async def is_learner_enrolled(learner_id, training_id) -> bool`

4. **Demonstrate personalization differences**:
   - Test with 3 different learner profiles (different `academic_level`, `employment_status`, `has_training_experience`)
   - Show that the same question gets meaningfully different answers
   - Document results in evaluation report

5. **Copilot system prompt tuning**:
   - Current system prompt is in `app/main.py::COPILOT_SYSTEM_PROMPT`
   - Add persona, tone guidance, and more explicit grounding rules

**Key data available for personalization**:

## Rules Everyone Must Follow

1. **Never write SQL outside `app/tsp_client.py`** — add a new method there instead
2. **Never hardcode credentials** — use environment variables
3. **All SQL must be parameterized** — `$1`, `$2` style, never f-strings in queries
4. **Validate with Pydantic before persisting** — nothing goes to the DB without schema validation
5. **Add your module's endpoints to `app/main.py`** — don't create separate FastAPI apps
6. **Test with the real demo training** — `45d3c920-abd2-4c4e-8fdf-497b9a6dd9fc`
